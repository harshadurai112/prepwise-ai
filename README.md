## 🤖 Introduction

MockMate is a cutting-edge platform designed to help you ace your job interviews. Powered by AI voice agents and seamless integration with modern web technologies, this platform offers personalized feedback and a smooth user experience. MockMate brings you a modern, AI-powered interview prep solution.

## ⚙️ Tech Stack

- **Next.js**: For building the user interface and backend logic.
- **Vapi AI**: For voice agent-based interactions during mock interviews.
- **Firebase**: For user authentication and data storage.
- **TailwindCSS**: For easy and customizable styling.

## 🔋 Features

- **Authentication**: Simple sign-up and login with Firebase authentication.
- **Create Interviews**: Generate mock job interviews powered by AI voice agents.
- **Instant Feedback**: Receive immediate feedback from AI after completing the interview.
- **Modern UI/UX**: Clean, user-friendly design with a focus on a great user experience.
- **Responsive Design**: Works seamlessly across devices.

## 🤸 Quick Start

### Prerequisites
Make sure you have the following installed on your machine:
- Git
- Node.js
- npm (Node Package Manager)

### Cloning the Repository
Clone the repository to your local machine:
```bash
git clone https://github.com/YOUR_USERNAME/mockmate.git
cd mockmate


// to run
npm install
//local .env
NEXT_PUBLIC_VAPI_WEB_TOKEN=
NEXT_PUBLIC_VAPI_WORKFLOW_ID=
GOOGLE_GENERATIVE_AI_API_KEY=

NEXT_PUBLIC_BASE_URL=

NEXT_PUBLIC_FIREBASE_API_KEY=
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=
NEXT_PUBLIC_FIREBASE_PROJECT_ID=
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=
NEXT_PUBLIC_FIREBASE_APP_ID=

FIREBASE_PROJECT_ID=
FIREBASE_CLIENT_EMAIL=
FIREBASE_PRIVATE_KEY=

//run
npm run dev
